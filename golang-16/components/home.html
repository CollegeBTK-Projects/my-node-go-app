Привет. Это сервер на Go

Доступные маршруты:

  • / — главная страница
  • /about — информация о разработчике
  • /contacts — контакты
  • /api/books — список книг (GET), добавление (POST)
  • /api/books/{id} — книга по ID (GET), обновление (PUT), удаление (DELETE)
  • /api/books/search?author=Толстой — поиск по автору
  • /error и /async-error — тест обработчика ошибок
